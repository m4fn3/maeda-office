法人を設立する場合、登記の前に準備を済ませたうえで、各提出先に以下の手続が必要となります。ここでは合同会社の設立を例に説明します。

## 設立の前に決めること・準備すること

{{< steps >}}
1. **会社の基本情報を決定する** … 商号（会社名）、事業目的、本店所在地、発起人の氏名と住所、資本金、社員構成、会計年度を決めます。
2. **印鑑を作成する** … 法人用の実印と認印を作成します。
3. **定款を作成する** … 決定した基本情報をもとに定款を作成します。
4. **出資金を払い込む** … 発起人の個人口座に出資金を払い込みます。
{{< /steps >}}

{{< note title="書類の綴じ方" >}}
- ①合同会社設立登記申請書、②登録免許税貼付台紙、③登記用紙と同一の用紙をホチキス留めし、①と②のページの間に《法人実印》で割印をします。
- ③の内容はCD-Rにも記録して提出します。
- 払込証明書は、通帳の表紙・裏表紙と振込のページと合わせて冊子にし、ホチキス留めします。
{{< /note >}}

### 登記完了後に取得する書類

登記が完了したら、登記事項証明書（登記簿謄本）2通と印鑑証明書1通を取得して提出します。

## 税務署に提出する書類

### 必ず提出するもの

- 法人設立届出書《法人実印》
- 青色申告の承認申請書《法人実印》
- 給与支払事務所等の開設届出書《法人実印》
- 源泉所得税の納期の特例の承認に関する申請書《法人実印》
- 定款

### 必要に応じて提出するもの

- 棚卸資産の評価方法の届出書
- 減価償却資産の償却方法の届出書
- 事前確定届出給与に関する届出書
- 適格請求書発行事業者の登録申請書

## 都道府県税事務所に提出する書類

- 法人設立等申告書

{{< note >}}
提出用と控用の2部を用意し、返信用封筒を同封して提出します。
{{< /note >}}

## 市役所に提出する書類

- 法人設立等申告書

{{< note >}}
登記簿謄本と定款のコピー、社員名簿を同封して提出します。
{{< /note >}}

## 労働基準監督署・ハローワーク・年金事務所に提出する書類

労働基準監督署・ハローワーク・社会保険事務所（現在の年金事務所）への手続は、個人事業の場合と同様です。提出書類と期限は「[個人事業主開業の際に必要な手続](/guide/kaigyo-setsuritsu/kojin-kaigyo/)」をご覧ください。

## まとめ

- 設立前に、基本情報の決定・印鑑の作成・定款の作成・出資金の払込みを済ませます。
- 法務局へは設立登記申請書など一式を提出し、登録免許税として**収入印紙6万円分**を貼り付けます。
- 登記完了後は、税務署・都道府県税事務所・市役所へ法人設立の届出を行います。
- 従業員を雇う場合の労働保険・雇用保険・社会保険の手続は、個人事業の場合と同様です。
